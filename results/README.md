# Results

`results/run/` is generated by:

```bash
seedmark experiment --output-dir results/run --trials 300 --length 80
```

or with Docker:

```bash
docker compose up --build
```

Each run contains:

- `report.html` — standalone interactive teaching report with animated token playback;
- `report.json` — full report payload including candidate probabilities and keyed scores;
- `summary.json` — machine-readable benchmark summary;
- `generated_watermarked.txt` / `generated_unwatermarked.txt` — matched generated examples;
- `trace_watermarked.csv` / `trace_unwatermarked.csv` — selected-token probabilities, PRF scores, and cumulative z-score;
- `trial_scores.csv` — per-trial detector results;
- `z_score_histogram.svg` — null vs marked z-score distribution;
- `roc_curve.svg` — empirical ROC curve.

With the default deterministic settings used during development (300 trials, 80 words, first word `research`, strength 1.5, top-k 8, threshold z=3), the local validation run produced approximately **99% detection**, **0 observed false positives in 300 null trials**, and **AUC 0.9999**. These are toy-model results, not claims about real LLMs or vendor watermark systems.
